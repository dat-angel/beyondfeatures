## About

Beyond Features is a newsletter and community for technical marketers, PMMs, and DevRel professionals who build for developer audiences.

Developer marketing has no playbook — so we're writing one. Weekly insights, real frameworks, and no fluff.

## What You'll Find Here

This repository contains assets, documentation, and resources for the Beyond Features project:

- **Brand assets** — logos, color palettes, typography
- **Documentation** — style guides, processes, and internal notes
- **Content planning** — editorial calendars, topic briefs
- **Resources** — tools, links, and reference materials

### Frameworks

- **[The Discovery Grid (agent-mediated buying)](resources/discovery-grid-agent-mediated-buying.md)** — two-axis GTM view: you finding buyers vs agents finding you; weekly prompts and a five-minute “invisible startup” check.
- **[Trust Debt scorecard (startups)](resources/trust-debt-scorecard-startups.md)** — security trust + market trust; 0–2 scoring to /20; interpretation bands (with [Amber Bennoui](https://www.linkedin.com/in/amber-bennoui/), Jiffy Labs).
- **[90-day trust playbook](resources/trust-debt-90-day-playbook.md)** — sequenced paydown plan (30 / 60 / 90) paired with the scorecard.
